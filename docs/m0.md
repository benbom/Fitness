## Definition of Done

- En användare kan registrera konto, verifiera mail, aktivera MFA och logga in — i staging, från en riktig telefon.
- Samma användare kan starta gratis testperiod, koppla Stripe-testkort, se sin prenumerationsstatus växla korrekt.
- Samma användare kan fylla i profil (mål, nivå, utrustning, skador) — och begära en export och få JSON+PDF via mail inom timmar.
- Samma användare kan radera sitt konto — och all data är borta ur primär och backup inom 24h, verifierbart.
- Alla externa credentials i Secrets Manager. Inget hemligt i repo. Inget okrypterat i backup.
- Trace från web-klick till databas-query syns i Grafana. Sentry pingar Slack när något nytt går fel.
- Deploy från main går grönt utan manuell hand. Rollback finns dokumenterat, testat, timeat.
- Runbooks för deploy, rollback, incident och KMS-rotation ligger i [`docs/runbooks/`](./runbooks/).
- Klass 1-data existerar ingenstans än, men infrastrukturen (KMS, separat schema, logg-filter) är på plats så att C-03 kan börja rent.
